# proto — 시안

기존 게임을 고치는 것이 아니라, **다시 세울 때 뼈대를 무엇으로 삼을지**를
돌려 보는 자리입니다. 리포의 `src/`와는 아무 것도 공유하지 않습니다.

## deeprun-delve — 걸어서 탐색하는 층 + 순서가 결과를 바꾸는 압력 체인

탐험 RPG의 뼈대(걸어서 층을 밝히고, 좁은 길과 방을 골라 다니고, 하강로를
찾는다)는 그대로 두고, 그 위에 다른 성공 공식을 얹었습니다.

| 가져온 것 | 어디에 |
| --- | --- |
| 스톤수프 | 걸어서 밝히는 층 · 한 줄로 읽히는 적 규칙 |
| 다키스트던전 | **위치가 곧 교전 규모** — 옆에 붙은 적은 전부 같이 나온다. 좁은 길에서 싸우면 하나만 상대한다 |
| 발라트로 | 압력계. 발생 → 증폭 → 방출이 눈앞에서 곱해진다 |
| 뱀서 | 교전은 자동으로 해소된다. 플레이어가 하는 일은 **미리 짜 두는 것** |
| 슬더스 | 부품함마다 3장 중 1장. 자리는 뽑은 뒤 끌어서 정한다 |
| 아이작 | 유물은 수치가 아니라 **체인의 규칙**을 바꾼다 (쌍둥이 축·공성 탄두·축압기) |

### 이 시안이 지켜야 할 주장

> 같은 모듈이라도 **순서가 다르면 결과가 다르다.**

주장을 지키지 못하면 순서 UI는 장식이므로, 벤치가 그것만 잽니다.
`node proto/delve.mjs` (사전에 `python3 -m http.server 8299`를 시안 폴더에서):

```
순서 벤치 — 같은 5모듈의 120가지 순열, 각 40회, 같은 적 3체
  최고      88  증기 보일러 → 점화 플러그 → 증폭 코일 → 과열 밸브 → 산탄 방출
  최저       3  산탄 방출 → 과열 밸브 → 증폭 코일 → 점화 플러그 → 증기 보일러
  격차  ×29.3
```

같은 다섯 조각으로 낸 피해가 3에서 88까지 벌어집니다. 순서는 장식이 아닙니다.
벤치는 이 밖에 「300걸음 무작위 워크가 실제로 걷고·싸우고·뽑는가」와
「탭-탭으로 순서가 바뀌는가」와 콘솔 오류 0건을 함께 봅니다.

### 굽기

```
node proto/build.mjs > proto/deeprun-delve.html
```

글꼴을 data URI로 박아 자립형 HTML을 만듭니다 (아티팩트는 외부 요청이 막혀 있음).
`proto/deeprun-delve.html`은 굽기 산출물이라 커밋하지 않습니다.
